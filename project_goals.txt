High-Level Flow

    User opens home page.
    Home page shows text box and button.
    User enters text and clicks analyze.
    JavaScript sends text to Flask endpoint.
    Flask endpoint calls sentiment analysis function.
    Flask returns formatted result (or error message).
    JavaScript displays response on page.
